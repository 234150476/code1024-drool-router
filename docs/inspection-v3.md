# 分组巡检与 Key 检测

v0.3.0 将独立服务收敛为两个检测入口。自动隔离、冷却恢复、调度回写和综合评分不再接入服务；不修改 code1024 源码。

## 定时巡检

管理员通过「巡检设置」进入独立的管理员页面，该页面只显示设置和「返回公开页」，不展示公开结果、检测入口或刷新按钮。普通用户不会看到设置入口；管理接口仍要求有效管理员登录。管理员为一个分组保存模型、思考强度、题目和白天运行时间。每轮在该分组内选取最近使用的一个账号；账号必须 active、schedulable=true、有有效 last_used_at，且没有过期、限流或临时暂停。候选不足时跳过，不改用其他分组或没有使用记录的账号。真实请求发出前再次验证分组和可调度状态。预览与执行采用题目和配置快照。

建议配置：Plus 分组，gpt-6.1-sol，high，Asia/Shanghai，白天间隔 60 分钟，22:00–09:00 暂停。每天 09:00、10:00……21:00 共 13 轮；夜间重启不补跑，排队任务在进入夜间后也不新发起请求。已发出的请求可以等待完成。相同计划同一时间槽最多排队一次，编辑配置不额外补跑该时间槽。

鹈鹕题目：`创建一个HTML，内容是SVG绘制一只鹈鹕骑自行车的2D动画`。

## Key 检测

用户登录 code1024 后，选择本人 Key、题目、模型和思考强度。请求经普通网关模型接口执行，遵循原 Key 的分组、计费与额度；不使用管理员机器 Key 调用模型。原始 Key 和登录 JWT 不持久化到任务。回答默认私有，用户主动公开后才出现在 Key 所属分组，可随时撤回。

## 展示与判定

结果页显示分组、检测轮次、模型、来源、耗时和题目。鹈鹕 HTML/SVG 通过独立作品接口与 opaque sandbox 渲染，允许内联脚本支持动画，但禁止联网、同源权限、表单与顶层导航。支持停止/重播、源码和复制。固定答案题展示原回答、识别答案、标准答案及通过/未通过/无法判定；指纹类只供参考；请求失败单独记录。

普通接口不返回账号 ID、账号名、用户 ID 或原始凭据。管理员历史接口在宿主管理员会话验证后返回巡检账号。私有作品使用本人会话生成十分钟签名链接。登录可见模式下，公开作品和私有作品的 iframe 均使用十分钟、仅限指定作品路径的随机预览凭证；服务端在每次访问作品时重新验证宿主登录状态，私有作品还会核对所有者。凭证仅保存在服务内存，容量最多 1024 条，过期或重启后需重新加载记录；用户 JWT 不会进入 iframe URL。

## 结果访问权限（v0.3.2）

管理员进入「巡检设置 → 结果访问权限」，配置「允许匿名查看结果」并单独保存。该开关作用于全部分组，默认关闭；旧 volume 升级时新增默认关闭的配置，不改变已有巡检、题目、凭据和历史。

- 关闭：全部 `/api/public/*` 结果、历史、回答和作品 API 必须验证有效的 code1024 登录。嵌入页沿用宿主会话；直接打开而未携带有效会话时只显示登录提示，不返回检测数据。
- 开启：访客可匿名查看已发布的分组结果、用户主动共享的结果和公开作品；不提供账号信息。
- 私有作品始终要求有效的本人登录；开启匿名也不会公开私有作品。巡检设置始终仅管理员可用，Key 检测始终要求本人登录。
- 管理 API：`GET /api/admin/access` 返回 `{revision, value: {allow_anonymous_results: false}}`，`PUT /api/admin/access` 提交相同结构；必须是真正的 JSON 布尔值，并通过 revision 检查并发更新，修改记录写入审计。

访问权限是独立服务的数据库配置，无需修改 Sub2API、Nginx 或 `config.json`。静态页面外壳可加载；受保护的是所有检测数据和作品。iframe 是否嵌入、Referer 和 URL 中的用户 ID 都不作为登录凭据。

## 机器凭据

专用 scoped admin Key 仅授予目标分组的 `accounts.read` 和 `groups.list.read`，限制平台和账号类型，不授予全权访问或任何写权限。密钥由管理员界面验证后保存于 `/data/private/automation-key`，权限 0600。

当前网关的受限 Key 不能读取账号令牌。宿主服务器用原管理员授权流程运行 `scripts/export_account_snapshot.py`，仅导出指定分组，保存在受保护文件。配置 `SUB2API_ACCOUNT_SNAPSHOT_FILE=/run/secrets/plus-account-snapshot.json`。脚本保留原二次验证边界，遇到 403 立即停止，绝不关闭保护。不要将管理员登录文件挂载到服务容器。

快照应每两分钟刷新，包括 OAuth 当前凭据、代理、实际分组、最近使用时间和配额策略。读取时验证账号身份、授权分组以及十分钟有效期；缺失、过期或身份不符时停止模型请求。账号 OAuth 刷新仍由网关负责。

宿主 systemd timer 只同步私有快照，实际模型请求由服务内部按每个分组的计划触发。凭据同步持续运行不代表夜间会调用模型。

## 升级与回滚

先停止新任务并备份 volume、config.json、compose.yaml，再升级独立服务。旧隔离表仅保留用于历史审计和回滚，v0.3.0 不再读取或执行；迁移去掉计划的隔离与回写开关，不修改网关账号状态。已有结果和原题目快照保留到保留期限。

管理 API 入口为 `/api/admin/inspections`，按分组保存，不再暴露原多模块控制台。生产 URL 可继续沿用 `/quality/` 与 code1024 自定义嵌入页面。
